How to stop KOReader hanging on Wi-Fi on your Kobo.

TechReader

With KOReader installed on the Kobo (I explain how in how to install KOReader on your Kobo), I ran into a really annoying habit. When I switched the Kobo on with a book open, it got stuck trying to connect to Wi-Fi and stopped responding. The odd thing was that if I then pushed my progress by hand, it connected straight away.

Why it happens

The culprit is automatic reading progress sync. KOReader can save the page you're on to a server, so you can pick up where you left off on another device. In a future article I'll explain exactly what it's for and how to set it up.

With automatic sync on, KOReader checks that server when you open or resume a book, and to do that it switches Wi-Fi on. The problem is that it does so just as the Kobo has woken up and the network isn't ready yet, and there it sits, waiting.

When you sync by hand, on the other hand, the Kobo has been awake for a while and Wi-Fi connects without any trouble.

The fix

Turn off automatic sync. Manual sync keeps working just the same and only switches Wi-Fi on when you ask for it.

With a book open, go to Tools → Progress sync and untick the option to sync automatically.

Since then, when I switch the Kobo on I'm straight back on the page I was reading, with no waiting.

Checking it's all set up

As with any setting, you can check the result on your computer. With KOReader closed, connect the Kobo over USB and open .adds/koreader/settings.reader.lua. In the ["kosync"] block (the internal name for sync) you should see:

lua
["kosync"] = {    ["auto_sync"] = false,   -- automatic sync turned off},

There will be more lines in that block, such as the server address and your username. Leave those alone.

In the same file, outside that block, Wi-Fi is best set up like this:

lua
["wifi_enable_action"] = "turn_on",   -- if an action needs Wi-Fi, switch it on["wifi_disable_action"] = "leave_on", -- don't switch it off afterwards

With these two values, when you sync by hand KOReader switches Wi-Fi on without asking and leaves it on, which is exactly what you want to make manual sync comfortable.

What you lose, and how to get it back

The trade-off is that if you've been reading the book on another device, opening it on the Kobo won't jump to where you left off on its own. You have to pull the progress in by hand.

To keep that from being a chore, I assigned sync to a gesture: a tap in the bottom right-hand corner of the screen. You set it up in KOReader's gesture settings by choosing the progress sync action. That puts it one tap away, without going through any menus.

Things to bear in mind

Only edit the settings file with KOReader closed. KOReader rewrites it when it exits, and one missing comma can stop it from starting. If you edit it by hand, make a copy first.

If you use a Bluetooth remote, Wi-Fi matters too. On the Libra Colour, Bluetooth needs Wi-Fi switched on to come back after waking. I cover it in how to set up Bluetooth remotes in KOReader on your Kobo.

Waking up without the wait

It's a small change, but you notice it every time you pick up the Kobo: you switch it on and you're reading. In exchange, one tap in the corner when I've been reading somewhere else, which seems a more than fair price to me.
