How to set up Bluetooth remotes in KOReader on your Kobo.

TechReader

I read on the sofa or in bed, with the e-reader on a floor-standing holder with an adjustable arm (one of my best buys of 2026). With the Kindle I turned pages with a clicker clamped to the reader that tapped the screen for me and covered part of it. With the Kobo I have the Kobo Remote, its official Bluetooth remote: two buttons and nothing attached to the device.

The Kobo's own reader recognises it out of the box. KOReader doesn't, because it doesn't handle the Kobo's Bluetooth on its own, so it needs setting up. I'm starting from KOReader already installed, as explained in how to install KOReader on your Kobo.

What you need

Bluetooth is added by the kobo.koplugin plugin: a menu to scan for, pair and connect devices, and a way to assign actions to the remote's buttons. If you followed the installation article, you already have it.

To check, open KOReader and go to Settings → Network. If there is a Bluetooth section, you're good to go.

Pairing the remote

You only need to do this once:

  1. In KOReader, go to Settings → Network → Bluetooth and switch Bluetooth on.
  2. Put the remote into pairing mode, as described in its manual. The LED starts blinking.
  3. Tap Scan for devices and, when the remote appears, select it to pair it.
  4. In Paired devices, open your remote and tick Trust. That way it can connect without asking for confirmation every time.
  5. Tap Connect. The remote should show as connected.

Assigning the buttons

Being connected isn't enough: you have to tell KOReader what each button does.

In the same remote submenu, go into Configure key bindings. Choose the "next page" action and, when prompted, press the button on the remote you want to use to go forward. Repeat with "previous page" and the other button.

If it doesn't pick up the button presses, restart KOReader and try again. It happened to me the first time and that sorted it.

Leave on the plugin option that dismisses pop-up windows when you press a button on the remote (it's on by default). That way you don't have to touch the screen to clear a notice.

Checking it's all set up

If something goes wrong, it's easier to check on your computer. With KOReader closed, connect the Kobo over USB and open .adds/koreader/settings.reader.lua. In the ["kobo_plugin"] block you should see something like this:

lua
["kobo_plugin"] = {    ["bluetooth_key_bindings"] = {        ["AA:BB:CC:DD:EE:FF"] = {               -- your remote's MAC            ["KEY_103"] = "Reader:prev_page",   -- previous page            ["KEY_108"] = "Reader:next_page",   -- next page        },    },    ["dismiss_widgets_on_button"] = true,    ["paired_devices"] = {        [1] = {            ["address"] = "AA:BB:CC:DD:EE:FF",            ["name"] = "Kobo Remote",        },    },},

What to look for:

  • paired_devices contains your remote, with its MAC address (the one in this example is made up, yours will be different).
  • bluetooth_key_bindings has two buttons assigned under that same MAC. KEY_103 and KEY_108 are the codes for my remote and yours may differ, so assign them from the menu and check them here rather than copying them.
  • The Reader: prefix depends on the language KOReader is set to. Mine is in Spanish, so in my file it shows as Lector:.

Keeping it working after sleep

With this, the remote worked until the Kobo went to sleep. When I woke it up, Bluetooth was still on but the remote didn't respond, and I had to disconnect it and reconnect it by hand in Paired devices.

The plugin turns Bluetooth off when the Kobo sleeps and back on when it wakes, but that doesn't reopen the connection to the remote. On top of that, detection of reconnecting devices was turned off and set to stop after the first connection.

The fix is in Settings → Network → Bluetooth → Settings:

  1. Leave Auto-resume after wake on, which turns Bluetooth back on when the Kobo wakes up.
  2. In the Auto-detection section, turn on Auto-detect connecting devices.
  3. In the same section, turn off Stop detection after connection.

Now all it takes is to switch the Kobo on and press a button on the remote to wake it: the plugin detects the reconnection and the buttons work again.

In the file, those three settings are these lines inside the same ["kobo_plugin"] block:

lua
["enable_bluetooth_auto_resume"] = true,          -- turn Bluetooth back on after waking["enable_auto_detection_polling"] = true,         -- detect remotes that reconnect["disable_auto_detection_after_connect"] = false, -- don't stop detection after the first connection

If Bluetooth doesn't come back on after waking, check in KOReader's Network settings that Wi-Fi is restored on resume. On the Libra Colour they share a chip, and Bluetooth needs Wi-Fi switched on to come back.

Things to bear in mind

Exit KOReader by restarting. According to the plugin documentation, exiting to the Kobo reader with Bluetooth on can freeze the system and restart the Kobo, and that restart sometimes loses the KOReader launcher. It hasn't happened to me, but just in case I always exit with the option to reboot the device in the Exit menu.

Continuous detection uses a bit more battery. It's the price of having the remote reconnect on its own.

Only edit the settings file with KOReader closed. KOReader rewrites it when it exits, and one missing comma can stop it from starting. If you edit it by hand, make a copy first.

Reader's paradise

KOReader with my settings, Kobo's own remote and nothing clamped to the screen. Since I set up automatic detection I haven't had to touch it again.

And in winter it's wonderful. Lying in bed or on the sofa, with your neck straight, the book at the right height thanks to the holder and the remote in your hand, under the blanket. You don't even have to take your hand out to turn the page. That's what reading should feel like.

If it doesn't work first time, you know what to do: restart KOReader and try again.
